# Dystopia

A rust-and-ash theme for [Omarchy](https://omarchy.org).

## Install

```bash
omarchy theme install https://github.com/jtreguer/omarchy-dystopia-theme.git
```

## Wallpaper credits

The wallpapers were generated with [Leonardo.ai](https://leonardo.ai) and ChatGPT, and upscaled to 4K
with [Upscayl](https://upscayl.org).

| Wallpaper | Description |
|-----------|-------------|
| `1-drowned-city.jpg` | Lone figure on a rusted pipe facing a flooded city of ruined towers |
| `2-dead-tank.jpg` | Rusting tank in a dust storm, wanderer in a gas mask |
| `3-dead-tank-sunset.jpg` | Abandoned tank and wanderer under a dim setting sun |
| `4-lone-survivor.jpg` | Survivor perched on a capsized trawler before a flooded city (ChatGPT) |
